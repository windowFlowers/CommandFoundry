# 5 分钟面试演示脚本

## 0:00–0:40 产品定位

“这是一个本地优先的开发者命令 RAG 助手。它不是聊天壳：答案尽量落到可复制命令，并同时给出平台、前置条件、危险提示和精确来源。v2.4 在父子块精确证据 RAG 之上增加了透明、可撤销的用户个性化记忆，重点展示从知识治理到有状态桌面 Agent 的完整闭环。”

展示启动后的六类入口和右下角知识状态。

## 0:40–1:40 三个核心问题

依次提问：

1. “在 Linux 中切换文件目录的指令是什么？”
2. “Git 怎么安全回滚一次提交？”
3. “MySQL 中怎么创建一个视图？”

展示命令复制、占位符、平台，以及正文和命令卡上的引用编号。强调 `git revert` 被排在安全回滚主题首位。

## 1:40–2:30 上下文记忆

先问“Linux 怎么查看端口占用？”，紧接着问“那 Windows 呢？”。展示回答旁的“上下文 · 1轮”标签，并打开抽屉查看本次使用的历史问题。再说明：查询改写只用于检索，历史不作为命令事实；切换知识库会创建新会话，清空上下文也不会删除聊天记录。

## 2:30–3:15 个性化记忆

在一个对话中说“请记住我主要使用 Windows 和 PowerShell”，展示“已记住”提示；若使用一条需要模型判断的模糊偏好，则展示任务从提取中到 ready、NOOP、失败或取消的状态反馈。新建对话后询问“怎么查看端口占用？”，展示优先返回 Windows 方案和“个性化 · N 条”标签。打开“我的记忆”，展示全局/知识库范围、来源、置信度、固定、编辑、撤销和删除。再明确指定“这次只说 Linux”，说明当前问题会覆盖历史偏好。

## 3:15–3:45 风险复核

提问“如何强制回滚 Git 到上一次提交？”或展示高风险测试。说明风险判断不交给模型单独决定：`git reset --hard`、强推、删除数据库、Docker prune 等会被后端规则二次复核。

## 3:45–4:10 离线降级

打开“模型设置”，点击“测试真实对话”，展示 token 与耗时。说明 Key 用 Windows DPAPI 加密且 Renderer 只能保存、测试、清除，不能读取。清除 Key 后再次提问，回答仍然出现，并显示准确的本地回退原因。

## 4:10–4:45 上传文档与精确引用

打开知识库管理，新建一个库并上传 Markdown，等待状态从“索引中”变为“就绪”，再用该库开始新对话。说明约 420 字符的子块进入 BM25 + BGE + RRF，命中后回填受限的章节父块用于生成，而引用始终落在实际命中的子块。点击回答中的 `[1]`，展示预览自动滚动到标题、行号和高亮文本；PDF 可定位页码，DOCX 可定位段落或表格行。补充说明每库索引按需加载，不需要向量数据库；若上传索引或已有索引重建被进程中断，下一次启动会安全重新排队，已有可用版本不会被清空。

## 4:45–5:00 工程闭环

展示评测报告：300 条单轮查询、60 组多轮查询、80 条上传文档父子检索，以及 60 组跨对话个性化场景。再指出 PyInstaller + electron-builder 产出 Windows 安装包；精确引用由文档哈希、索引 revision 和定位快照保证可核验，长期记忆则有作用域、来源、替代链和物理删除边界。

收尾： “这个版本的取舍是把可靠性、可解释性和可交付性做完整，而不是堆叠后台、Graph RAG 或多 Agent。下一步若数据规模增长，再用真实离线数据决定是否引入 reranker 或向量数据库。”
