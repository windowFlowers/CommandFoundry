# 5 分钟面试演示脚本

## 0:00–0:40 产品定位

“这是一个本地优先的开发者命令 RAG 助手。它不是聊天壳：答案尽量落到可复制命令，并同时给出平台、前置条件、危险提示和来源。v2.1 内置 14 个常用开发领域，并支持隔离的自定义知识库，重点展示从知识治理到桌面交付的闭环。”

展示启动后的六类入口和右下角知识状态。

## 0:40–1:40 三个核心问题

依次提问：

1. “在 Linux 中切换文件目录的指令是什么？”
2. “Git 怎么安全回滚一次提交？”
3. “MySQL 中怎么创建一个视图？”

展示命令复制、占位符、平台与来源折叠区。强调 `git revert` 被排在安全回滚主题首位。

## 1:40–2:30 风险复核

提问“如何强制回滚 Git 到上一次提交？”或展示高风险测试。说明风险判断不交给模型单独决定：`git reset --hard`、强推、删除数据库、Docker prune 等会被后端规则二次复核。

## 2:30–3:20 离线降级

打开“模型设置”，点击“测试真实对话”，展示 token 与耗时。说明 Key 用 Windows DPAPI 加密且 Renderer 只能保存、测试、清除，不能读取。清除 Key 后再次提问，回答仍然出现，并显示准确的本地回退原因。

## 3:20–4:20 技术架构

打开知识库管理，新建一个库并上传 Markdown，等待状态从“索引中”变为“就绪”，再用该库开始新对话。解释每库独立 BM25 + BGE + RRF、懒加载内存矩阵，不引入向量数据库；DeepSeek 只整理命中，Pydantic 校验失败就回退。

## 4:20–5:00 工程闭环

展示评测报告：300 条查询的混合检索 Top-3 99.33%，三个核心问题 Top-1 100%；再指出 PyInstaller + electron-builder 产出 Windows 安装包，知识在固定提交、manifest 和来源锁中可追溯。

收尾： “这个版本的取舍是把可靠性、可解释性和可交付性做完整，而不是堆叠后台、Graph RAG 或多 Agent。下一步若数据规模增长，再用真实离线数据决定是否引入 reranker 或向量数据库。”
